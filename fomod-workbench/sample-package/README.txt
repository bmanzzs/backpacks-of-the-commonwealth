TRAILBOUND / FIELD KIT — FOMOD WORKBENCH SAMPLE

This is a fictional package for testing the viewer.
The ESP, DDS, and NIF files are plain-text simulation fixtures, NOT working game files.
Do not install this sample in a game or a mod manager.

Open this whole sample-package folder in FOMOD Workbench.
Try 2K or 4K, enable weathering to reveal a third page, and set CompanionMod.esp to Active in the simulated environment.
The weathering texture supersedes the chosen base color texture because its priority is higher.
Built-in demo file sizes are illustrative; importing this folder shows actual fixture sizes.

All text and schematic artwork were created for this demo.
